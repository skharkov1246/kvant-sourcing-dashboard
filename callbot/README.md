# Звонилка поставщикам

Голосовой агент дожимает молчащих поставщиков. Решения владельца от 31.10.2026:
- звонит только агент, только на английском;
- агент ссылается на наше отправленное письмо;
- номера можно брать в любой стране;
- в начале звонка агент не объявляет, что он ИИ, но на прямой вопрос всегда отвечает правду.

Полный алгоритм лежит у владельца в PDF «Звонилка: алгоритм построения».

Группа gpt: Telnyx набирает, при ответе человека (или после сигнала автоответчика) переводит звонок на OpenAI Realtime по SIP; разговор ведёт Durable Object `CallSession`. Подписи всех вебхуков проверяются. Деплоя и расписания нет: набор закрыт `CALLS_ENABLED=0` |

## Что дальше

Запуск обработчика (владелец; агенту ключи не передаются):

1. Telnyx: проверка второго уровня. Иначе 2 одновременных звонка и не все страны. В исходящем голосовом профиле разрешить CN, HK, AE, IN, SG и страны Юго-Восточной Азии. Номера по пулам: HK, SG, GB. Приложение Call Control с адресом `https://<воркер>/telnyx`. FQDN-подключение для ElevenLabs (`sip.rtc.elevenlabs.io`, вход по логину и паролю).
2. OpenAI: проект, его `proj_…`, вебхук проекта на `realtime.call.incoming` с адресом `https://<воркер>/openai`.
3. ElevenLabs: агент с разрешёнными подменами промпта и первой фразы. Номера Telnyx импортированы как SIP-транк. Инструменты-вебхуки `https://<воркер>/eleven/tool/<имя>` с заголовком `X-Callbot-Secret`, в теле — `job_id` из переменной. Итоговый вебхук `https://<воркер>/eleven/postcall`. Системный инструмент `voicemail_detection`.
4. Битрикс: вебхук записи (комментарии, задачи, смарт-процессы) — в секрет `BITRIX_WRITE_WEBHOOK_URL`.
5. Секреты и переменные — список в `callbot/worker/wrangler.toml`. Деплой: `npx wrangler deploy` из `callbot/worker`.
6. Пробный звонок на свой номер по каждой группе, затем `CALLS_ENABLED=1` и расписание `*/5 * * * *`.

Схема «набор Telnyx → перевод на OpenAI» в документации целиком не описана: OpenAI по SIP принимает только входящие. Её проверяет первый пробный звонок.

Без доработки Битрикса (решение владельца 31.10.2026): попытки, обещанные даты и «не звонить»
хранит журнал обработчика (Durable Object `Ledger`), а не поля карточки. Повторную отправку письма
делает сорсер по задаче: через REST письма не уходят. Название нашей компании и имя агента —
переменные репозитория `CALL_OUR_COMPANY` и `CALL_AGENT_NAME` (для очереди) и те же секреты воркера.

Пилот: группы GPT-Realtime-2, ElevenLabs и контроль (без звонков) по хешу компании. Качество
разговора оценивает робот (`call-eval.yml`); мерило пользы — доля КП через 10 рабочих дней
против контрольной группы.

В репозитории нет ни номеров, ни названий поставщиков, ни адресов: всё это лежит только в
закрытом ключе KV и в Битриксе.
