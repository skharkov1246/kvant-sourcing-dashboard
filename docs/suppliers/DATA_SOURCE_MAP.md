# Карта источников: бизнес-факт → откуда берётся

Заполнено фактическими именами после аудита 20.09.2026. Колонка «запрещённая
подмена» — не теория: каждая строка в ней описывает подмену, которая в коде
**уже сделана** либо была бы сделана по умолчанию.

## Что из этого годится в заголовок отчёта

Годится: число заказов СП-172, сумма закупки по СП-172, число запросов, число
ответов с файлом, число артикулов с твёрдым наличием и подтверждённым объёмом.

Не годится без оговорки рядом: любая сумма, полученная домножением цены на
количество без `covers_qty == full`; любой срок ответа, посчитанный по движению
стадии; любое «в срок» без фактической даты приёмки; любая сумма, смешивающая
валюты без даты и источника курса.
