|---|---|---|
| правила, код, агрегаты замеров, номера прогонов и PR | репозиторий (`docs/agents`, `docs/kb`) | публичный, читается каждым агентом при старте |

## Роли

| роль | что делает | где пишет состояние |
|---|---|---|
| архитектор | ведёт очередь, раскладывает задачи по направлениям, записывает решения владельца, принимает итог сессии | `QUEUE.md`, `DECISIONS.md` |
| КП и цены | разбор КП поставщиков и наших КП, цена, недельный свод | `kp-prices/STATE.md` |
| бренды и коды | `dict/oem.json`, канонические бренды, коды запчастей | `brands-codes/STATE.md` |
| поставщики | реестр компаний, `/suppliers`, сведение, ИНН | `suppliers/STATE.md` |
| библиотеки ГТУ-ГПУ-ГШО | цепочка «машина → … → исполнитель» | `libraries/STATE.md` |
| портал | дашборд, вкладки, ревизия вкладок (`portal-audit`) | `portal/STATE.md` |
| скептик | опровергает вывод до записи: второй способ замера, «у скольких хуже» | в PR и в STATE направления |

Доли ресурса (24.09.2026): пятая часть — разведка брендов (приостановлена для внешних
источников 29.09.2026), пятая часть — ревизия вкладок, остальное — очередь.

## Сессия агента

1. Старт: `CLAUDE.md` → `.agent/manifest.json` → `docs/kb/INDEX.md` → `QUEUE.md` →
   STATE своего направления.
2. Берёт одну строку очереди. Большая работа делится на 10–50 частей.
3. Правка данных: холостой замер → «у скольких хуже» → второй способ проверки → запись.
4. PR через гейт; мерж — после зелёного гейта (и «Живой сверки метрик» для расчёта).
5. Финиш: STATE направления (агрегаты, номер прогона, PR, следующий шаг), страница
   Notion направления (коммерческие детали), строка `QUEUE.md`.

## Границы агентской сессии (распоряжение владельца 30.09.2026)

- закрытых ключей у агента нет: секреты живут только в секретах прогонов Actions и
  Cloudflare;
- зашифрованных выгрузок базы агент не заводит, не скачивает и не хранит;
- расшифровки у агента нет;
- замер по закрытым данным идёт внутри прогона, наружу — только агрегаты.

## Что считается готовым

- цифра имеет прогон или PR и дату;
- у правки «в среднем лучше» посчитано, у скольких стало хуже;
- следующий шаг назван в STATE и стоит в очереди.
