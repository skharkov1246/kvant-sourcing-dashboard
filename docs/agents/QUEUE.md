## Дефекты счётчика цепочки, названные и не правленные (ревизия 09.10.2026)

Ревизия в четыре разреза прошла по `scripts/build_chain_coverage.py`. Правка 09.10
привела к одной единице измерения клетку «Машина» у шести направлений из семи;
остальное названо, воспроизведено числом и оставлено — это другие клетки, и
каждая правка требует своего замера. Все числа проверены запуском.

| # | клетка | дефект | число |
|---|---|---|---|
| 11.1 | recip · Машина | считаются подтверждённые НАХОДКИ разведки, а не машины; через `машины()`/`mkey_model` не проходит | n = 21 при 0 записей recip в реестре; «Место производства линейки API 618» — не машина |
| 11.2 | gsho · Запчасть | `put()` с 561 номером из `r1700.json` затирается прямым присваиванием ниже; номера в `unique_pns('gsho')` не входят | 1 874 вместо 2 344, провенанс r1700 потерян |
| 11.3 | recip · Изготовитель | нет фильтра `MAKES`/`NOT_MAKES`, который стоит у насосов: в изготовители идут ремонтные заводы, трейдеры, НИИ и тендерные площадки | 216 вместо 159; 49 компаний с пометкой «сервис/дистрибьютор» |
| 11.4 | все · Изготовитель | `tier1`/`tier2` в `subsupplier_recon.json` — повествовательный текст; `nkey` режет его в ключ, и «Не установлен (…)» становится изготовителем, а одна компания даёт несколько ключей | 28 мусорных ключей; pumps 84 вместо 93 |
| 11.5 | gpu/gtu/gsho · Признак, Дефект, Ремонт | `faults_links()` пишет только подтверждённое и НЕ пишет черновик, хотя все прочие источники пишут | по ГПУ теряется 51 строка из 79 |
| 11.6 | recip · Изготовитель | в источниках клетки не назван `subsupplier_recon.json`, давший 25 ключей из 216 | провенанс потерян |
