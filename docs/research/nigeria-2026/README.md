# Нигерия 2026 — исследование рынка и пять направлений

Отчёт для владельца (05.09.2026): текущее состояние рынка Нигерии (переработка, газ, сера,
катализаторы, ротационное оборудование, горнодобыча, деловая среда) и пять направлений входа
с экономикой и планом на 90 дней.

- `Nigeria_2026_KVANT_5_directions.pdf` — итоговый отчёт (12 стр.)
- `index.html` + `style.css` — исходник отчёта; PDF собран headless Chromium
  (`chromium --headless --print-to-pdf=... --no-pdf-header-footer index.html`)
- `facts_raw.md` — сводка фактов четырёх исследовательских потоков с числами

Данные публичные (регуляторы, Comtrade/WITS, отчёты компаний). Оценки помечены [О].

- `Nigeria_Sulfur_RotatingService_Scheme.pdf` + `deck_sulfur_rotating.html` — презентация‑схема входа по двум направлениям (сера, сервис динамического оборудования): точки входа, легализация, структура, дорожная карта.

- `Nigeria_Pitch_3_slides.pdf` + `pitch_3_slides.html` — пич партнёру на 3 слайда: кто мы (сера, сервис ГТУ/насосов), клиенты нефтегаза и энергетики с парком оборудования и интересом по каждому.
- `facts_clients_equipment.md` — факты по клиентам и оборудованию (Flowserve, парк ГТУ, сера, Dangote, NLNG/Indorama, энергокомпании) с источниками.
- `verification.md` — результаты адверсарной проверки 18 утверждений пича (подтверждено/исправлено/не подтверждено) со ссылками.
