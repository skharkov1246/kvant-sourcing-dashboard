## Правила

- Ключ — `nkey(name)`; все написания одной компании — под одним ключом с указанием, где
  найдено (`spellings[].where`).
- Поле `kind`: бренд, указание (к закупке), несколько брендов в одной записи, описание,
  номер. Указание — не бренд, но для сорсера ответ не хуже имени завода.
- Бренд с владельцем не сливается: марка на шильдике остаётся брендом, холдинг — поле
  `owner` (`library/brand_owner.py`).
- Торговое название материала (Teflon, Viton) — написание материала, а не бренд
  (`dict/material.json`).
- Целевая схема: группа → бренд → юрлица → написания. Образец — Grundfos (9 записей-юрлиц
  сейчас отдельными брендами); запись — после замера «у скольких хуже».
- Код запчасти в разведке — только с дословной цитатой источника
  (`scripts/brand_research_check.py`). Внешняя разведка приостановлена 29.09.2026.
