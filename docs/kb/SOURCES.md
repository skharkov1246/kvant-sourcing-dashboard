## Правила

- Битрикс: ≤ 2 запросов/с на портал на все прогоны, `bitrix_client.интервал_портала()`;
  на 429/503 ждать; журнал прогона кончается строкой «портал: запросов …».
- Ежедневно — только инкремент.
- Цифра журнала — подмножество; итог спрашивают у базы (прогон `library-stats`).
- В журнал — только агрегаты.
