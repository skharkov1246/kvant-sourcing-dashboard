## Правила

- Данные поставщиков — только за входом (KV, Supabase); в git — код, DDL, придуманные
  фикстуры (Р-1).
- Ключ поставщика — вечный и бессмысленный `KV-S-NNNNNN-C` (А-4); сведение — по ИНН или
  налоговому номеру.
- Три оси наличия — `verdict`, `stock_grade`, `covers_qty`; складывать запрещено (А-5).
- Правка человека — таблица-спутник, импорт её не перезаписывает (А-6, А-7).
- Прямое предложение — только бренд или производитель; прочие — трейдеры.
- Решения — `docs/agents/DECISIONS.md`; состояние — `docs/agents/suppliers/STATE.md`.
