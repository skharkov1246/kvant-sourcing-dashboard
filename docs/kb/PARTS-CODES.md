## Правила

- Позиция — пара «бренд + код». Код без бренда — не позиция.
- Ключ артикула `lib_pn_key`: нижний регистр, без посторонних знаков; база только в
  UTF-8 (LESSONS, правило 21а), иначе ключи считаются иначе, чем на живой базе.
- Код из разведки — только с дословной цитатой источника.
- Стандартная деталь с размером («DIN 471 25») — код; правило `docfilter` сейчас
  считает её «не кодом» (открыто).
- Коды в репозитории допустимы (номенклатура открыта), цены по кодам — только в Notion.
