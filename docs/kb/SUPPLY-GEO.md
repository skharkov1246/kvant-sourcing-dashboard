# География поставок

Закрытая страница: https://app.notion.com/p/3eb74b7ffc6481119445e4b826deb24a

## Что есть

- Индексы цен по странам — `data/inflation/cpi_monthly.json` (прогон `library-cpi`,
  источник МВФ): для индексации цены по валюте.
- Происхождение модельного ряда — поле `origin` в `dict/model_series.json`: западный,
  китайский, прочий.
- Таможенные декларации ГШО — набор «база ЗИП · таможня» в `data/catalog.json`
  (18 наборов, конфиденциально; прогон `zip-customs`).
- Страна поставщика в `/suppliers` (`country`) пока не пишется — открыто.

## Правила

- Цена сравнивается на стандартном базисе (FCA, EXW); доставка и ввоз — отдельной строкой.
- Индексация — по индексу валюты цены, а не страны поставщика.
- Поимённые списки изготовителей по странам (в том числе китайских ODM) — только в Notion.
