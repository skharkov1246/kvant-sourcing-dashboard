# Глоссарий

Закрытая страница: https://app.notion.com/p/3eb74b7ffc6481c8a833f923300a25e0

| термин | значение |
|---|---|
| сорсер | сотрудник, который ищет поставщиков и собирает КП по заявке |
| КАМ | ключевой менеджер клиента; атрибуция сделки — поле «КАМ» (`UF_CRM_1740390857`) |
| продукт-оунер | ведущий продуктовой линии; поле «Product leader» (`UF_CRM_1779187425`) |
| запрос поставщику | карточка смарт-процесса Bitrix «Запросы поставщикам», entityTypeId 166 |
| КП | коммерческое предложение: поставщика нам (цена закупки) или наше заказчику (цена продажи) |
| ТКП | техническое и коммерческое предложение; наш документ заказчику в стиле `tkp-vedomost` |
| RFQ | запрос цены у поставщика; кампания запросов — навык `supplier-rfq` |
| наше КП | КП, которое мы выдали заказчику; поток цен «наше КП заказчику» |
| наша цена | цена позиции из нашего КП; сравнивается с ценой поставщика по той же позиции |
| недельный свод | еженедельное сравнение цен поставщиков с нашими КП по коду (`scripts/weekly_offers.py`) |
| пара | строка поставщика и строка нашего КП с одним кодом; сравнима при одной единице, валюте и базисе |
| позиция | пара «бренд + код» на всех страницах портала |
| OEM | владелец конструкции и бренда на шильдике |
| ODM | изготовитель, делающий изделие для OEM или вместо него |
| прямое предложение | предложение от самого бренда или производителя, включая дочернюю компанию |
| трейдер | всё, что не прямое предложение: дилер, дистрибьютор, склад |
| базис | условия поставки; стандартные — FCA и EXW, прочие со стандартными как равные не сравниваются |
| без НДС | правило сравнения: цена «с НДС» делится на ставку с пометкой «пересчитано» |
| индексация | цена на дату КП, пересчитанная на инфляцию валюты цены; показывается рядом, не в заголовке |
| свежая цена | цена не старше 180 дней |
| F1–F6 | шесть правок разбора наших PDF-КП за флагами (PR #488); F4 — шапка в две строки |
| холостой прогон | прогон без записи: меряет эффект правки до применения |
| «у скольких хуже» | число единиц, которым правка сделала хуже, при улучшении в среднем |
| `APPLY_ONLY_BETTER` | запись переразбора пропускает файл, у которого цен убыло |
| `lib_demand` | строки спроса из вложений Bitrix (~1,45 млн); сырьё для машин, узлов и запчастей |
| `lib_row_junk` | таблица-спутник пометок мусора; пометка вместо удаления |
| `lib_pn_key` | ключ артикула: нижний регистр, без посторонних знаков; база обязана быть в UTF-8 |
| `covers_qty` | покрывает ли подтверждённый остаток всё количество; не `full` — в сумму не идёт |
| цепочка | машина → узел → признак → дефект → ремонтное решение → запчасть → исполнитель |
| ГТУ · ГПУ · ГШО | газотурбинные установки · газопоршневые установки · горно-шахтное оборудование |
| ЗИП | запасные части, инструмент и принадлежности; сайт ГШО |
| KV | хранилище Cloudflare Workers KV, снимки для страниц портала |
| гейт | `.github/workflows/gate.yml` — проверки перед мержем |
| живая сверка | `live-check.yml` — сравнение метрик прода и правки на одном снимке портала |
| скептик | проверка вывода на опровержение до записи |
