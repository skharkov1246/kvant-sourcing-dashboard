# Схема проекта на несколько страниц

`shema-portala.html` — схема «что мы строим» для разговора с руководством:
поток сделки из восьми шагов, четыре замера потерь, шесть слоёв системы, план из
восьми этапов и пять решений, которые нужны от руководства. Пять страниц A4
landscape. Собрана 20.09.2026.

## Главное: от чего идти

**Мы делаем портал управления поставщиками.** Заявка → спецификация → подбор
адресатов → запрос поставщику (СП-166) → котировка → выбор → заказ (СП-172) →
поставка. Схема идёт по этому потоку.

Библиотека оборудования (машина → узел → признак → дефект → решение → запчасть →
изготовитель) — **опора шага «подбор адресатов»**, а не сама задача. Первая
версия схемы была построена от неё, и это была ошибка: владелец поправил
20.09.2026. Раздел «Куда мы идём» в `CLAUDE.md` описывает именно библиотеку,
поэтому брать его как описание всего проекта нельзя.

## Собрать PDF

```bash
/opt/pw-browsers/chromium-1194/chrome-linux/chrome \
  --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
  --run-all-compositor-stages-before-draw --virtual-time-budget=20000 \
  --print-to-pdf=shema.pdf file://$PWD/docs/schema/shema-portala.html
python scripts/pdf_check.py shema.pdf --expect "862" --expect "СП-172"
```

Правила вёрстки — `docs/ПРАВИЛА-PDF.md`. Таблицы текут сами, страницы вручную не
нарезаны, обрезки текста нет. Ссылки в просьбах к владельцу показаны адресом, а
не подписью: документ читают и на бумаге (корневое правило ссылок в `CLAUDE.md`).

**Ошибка, которую здесь уже сделали.** В первой версии схемы стояло «отклик
20 %» как общая цифра. На деле 20 % — это 176 КП из 862 запросов **по нашей
номенклатуре за девять месяцев**; по всей базе запросов 18 644 и КП 2 641, то
есть 14 %. Обе цифры верны и отвечают на разные вопросы. Подставляя число из
чужого замера, проверяй, по какой выборке оно считано.

**Чего схема не считает сама.** `data/chain_coverage.json` считает заполняемость
по файлам репозитория и библиотеку в Supabase не видит — его цифры ниже и
означают другое. Складывать их с цифрами из `CLAUDE.md` нельзя.
