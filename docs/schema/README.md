# Схема проекта на одну страницу

`shema-proekta.html` — схема «что мы строим» для разговора с руководством:
цепочка из семи звеньев с заполняемостью каждого, опоры, порядок работ и три
вопроса к руководству. Собрана 20.09.2026.

## Собрать PDF

```bash
/opt/pw-browsers/chromium-1194/chrome-linux/chrome \
  --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
  --run-all-compositor-stages-before-draw --virtual-time-budget=20000 \
  --print-to-pdf=shema.pdf file://$PWD/docs/schema/shema-proekta.html
python scripts/pdf_check.py shema.pdf
```

Правила вёрстки — `docs/ПРАВИЛА-PDF.md`. Таблицы текут сами, страницы вручную не
нарезаны, обрезки текста нет; проверено `pdf_check.py`.

## Откуда взята каждая цифра

Цифры проставлены **вручную** на 20.09.2026 — это снимок, а не счётчик. Обновляя
схему, сверяйся с источником, а не правь на глаз.

| В схеме | Источник |
|---|---|
| заполняемость семи звеньев (132 машины, 126 узлов, 24 признака, 16 дефектов, 45 ремонтных операций, 12 899 деталей) | таблица звеньев в `CLAUDE.md`, раздел «Куда мы идём» |
| 9 997 сущностей, 9 432 номера, 393 отложено, 534 в очереди | `docs/suppliers/STATE.md`, прогон `merge-1789942261` |
| 32 ИНН из 8 298 (0,4 %) | `docs/suppliers/STATE.md`, замер 20.09.2026 21:50 |
| 19 → 1 достижимая таблица | `docs/suppliers/DECISIONS.md`, решение Р-6 |
| 1,45 млн строк спроса | `CLAUDE.md`, `lib_demand` |
| 171 склеенная запись | `docs/suppliers/STATE.md`, разбор дефекта опознания |

**Чего схема не считает сама.** `data/chain_coverage.json` считает заполняемость
по файлам репозитория и библиотеку в Supabase не видит — его цифры ниже и
означают другое. Складывать их с цифрами из `CLAUDE.md` нельзя.
