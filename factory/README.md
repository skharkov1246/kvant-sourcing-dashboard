# Базовый проект золото-медного ГОКа (проба Л-1)

Статический сайт с проработкой проекта горно-обогатительного комбината: от карьера
до сплава Доре. Деплоится отдельным проектом Cloudflare Pages `kvant-gok`
воркфлоу `.github/workflows/factory-deploy.yml`.

## ⚠️ Сайт открытый

В `factory/public` **намеренно нет `_worker.js`** — значит, Cloudflare Pages отдаёт
статику всем желающим без пароля. Так распорядился владелец 17.08.2026.
Остальные сайты репозитория (дашборд сорсеров, ОВЭ-75, ГПУ, ЗИП) закрыты Basic Auth
и этим решением не затронуты.

Чтобы закрыть сайт: скопировать `ove/public/_worker.js` в `factory/public/`
и добавить в воркфлоу шаг записи секрета `BASIC_AUTH_PASS` (образец — `gpu-deploy.yml`).
Проверка в воркфлоу специально падает, если `_worker.js` появится незамеченным.

В `<head>` стоит `robots: noindex, nofollow` — ссылка работает у всех, но страница
не попадает в поисковую выдачу. Убрать эту строку, если нужна индексация.

## Что внутри

`public/index.html` — одна самодостаточная страница на 13 вкладок, весь CSS, JS,
таблицы и графика встроены. Сборки нет: файл деплоится как есть.
Внешних ресурсов быть не должно — воркфлоу это проверяет.

Содержание: резюме и выводы, характеристика сырья и геометаллургия, горные работы,
технологическая схема с таблицей потоков, инженерные расчёты и балансы (измельчение
по Бонду, флотация, вода, энергия, реагенты), спецификация оборудования, поставщики
и стратегия контрактации, инфраструктура и генплан, CAPEX/OPEX, экономика с DCF
и чувствительностью, экология и риски, график реализации, открытые вопросы.

## Исходные данные

- Технологический отчёт ЦНИГРИ по пробе Л-1 (вещественный состав, гравитация,
  флотация, сорбционное цианирование, фотометрическая сепарация).
- Календарный план отработки 2029–2039 гг.
- Котировки металлов на 17.08.2026.

Оценка капитала и операционных затрат — класс 4 AACE (±25 %), не заменяет ТЭО.
Показатели извлечения приняты по лабораторным испытаниям без масштабного коэффициента.
Местоположение объекта в исходных данных не задано, инфраструктура принята условно.

## Правка

Отредактировать `public/index.html`, проверить локально в браузере
(нет JS-ошибок, нет горизонтального оверфлоу, открываются все вкладки),
затем PR в `main`. Пуш в `main` с изменениями только в `factory/**` запускает
`factory-deploy.yml` (~1 мин) и **не** запускает пересборку дашборда:
`factory/**` внесён в `paths-ignore` воркфлоу `deploy.yml`.
