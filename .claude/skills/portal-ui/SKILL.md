# Интерфейс портала

Замер 01.10.2026: в портале четыре разных акцентных цвета (`#73b6ff` — `public/*.html`
и `portal_search.js`, `#5aa9ff` — `public/_worker.js`, `#f5a524` — дашборд,
`#205d45` — `public/archive.html`); стили встроены в каждую страницу, общего файла нет;
разметки `role="tab"` / `aria-selected` нет ни на одной странице. Правки ведутся
постепенно: одна страница — одна правка, без переписывания соседних.

## 1. Цвета и стиль

- Страница остаётся самодостаточной (встроенный CSS, как у соседей — LESSONS, «Стиль
  работы»), но цвета задаются переменными в `:root`, а не числами в правилах:
  `--bg`, `--fg`, `--muted`, `--line`, `--accent`, `--ok`, `--warn`, `--bad`.
- Акцент портала — `#73b6ff` (большинство страниц). Новую страницу не красить своим.
- Тёмная и светлая тема — переопределением тех же переменных, а не вторым набором правил.

## 2. Состояния

Каждый блок, который грузит данные, показывает одно из трёх состояний одним текстом
на всех страницах:

| состояние | текст | когда |
|---|---|---|
| загрузка | «Загружаю…» | запрос ушёл |
| пусто | «Нет данных» + чего нет и откуда должно прийти | ответ пустой (решение Р-2: не придумывать) |
| ошибка | «Не удалось загрузить» + код ответа | 4xx/5xx, сеть |

Пустой график без подписи — дефект: так год молчал график прогноза (LESSONS, «Числа»).

## 3. Вкладки и клавиатура

- Список вкладок — `role="tablist"`, вкладка — `role="tab"` + `aria-selected` +
  `aria-controls`, панель — `role="tabpanel"`. Переключение стрелками.
- Видимая рамка фокуса; область нажатия не меньше 24 × 24 px.
- Вкладка должна иметь адрес (`#вкладка`), на который можно вернуться.

## 4. Телефон

- Ширины проверки: 390, 768, 1280 px. На 390 — без горизонтальной прокрутки
  страницы; широкая таблица прокручивается внутри своей обёртки.
- Шапка и фильтры складываются в столбец; цифры KPI не мельче 14 px.

## 5. Рабочая таблица (сотни строк)

Образец для этапа 4 плана («Рабочая таблица спецификации»):
- закреплённая шапка (`position: sticky`), первый столбец — позиция «бренд + код»;
- вставка из Excel (буфер обмена, табуляция → столбцы) с предпросмотром до записи;
- работа с клавиатуры: стрелки, Enter — правка, Esc — отмена;
- числа — по правому краю, валюта и базис рядом с ценой, пометки «письмо»,
  «пересчитано», «индексировано» — текстом, не цветом;
- без обрезки текста в ячейке; длинное — переносом.

## 6. Проверка до PR

1. Smoke-сборка и `python scripts/validate_dashboard.py smoke/index.html` (гейт).
2. Снимок в headless Chromium на трёх ширинах (Playwright уже стоит,
   `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`):
   ```python
   from playwright.sync_api import sync_playwright
   with sync_playwright() as p:
       b = p.chromium.launch()
       for w in (390, 768, 1280):
           pg = b.new_page(viewport={"width": w, "height": 900})
           pg.goto("file:///…/smoke/index.html"); pg.screenshot(path=f"/tmp/shot_{w}.png", full_page=True)
   ```
   Снимки посмотреть самому (инструмент чтения изображений) до PR.
3. Тексты интерфейса — по-русски, без сырых кодов (`pn_not_found` → словарь).
4. Данные вкладки — навык `portal-audit`, отдельной правкой.
