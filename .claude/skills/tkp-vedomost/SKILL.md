# Стиль документов: ведомость на белой бумаге

Распоряжение владельца (04.09.2026): все КП, ТКП и документы — в строгом стиле, шрифт
Times New Roman, «стиль ведомостей, но на белой бумаге», без типичных для ИИ выделений
строк и разнесения текста. Это правило действует для всех документов проекта.

## Обязательные правила

1. Шрифт — Times New Roman (в контейнере его подменяет метрически совместимый
   Liberation Serif; стек: `"Times New Roman", "Liberation Serif", "FreeSerif", serif`).
   Основной текст 11 pt, таблицы 9,5 pt, интерлиньяж 1,28, выключка по ширине.
2. Только чёрный текст на белом фоне. Никаких цветных заголовков, плашек, «ключевых
   выводов» в рамках, тегов-статусов, зебры в таблицах, иконок и эмодзи.
3. Никаких жирных выделений внутри абзацев и в начале пунктов списков. Жирный шрифт не
   используется вообще; курсив — только для подзаголовков третьего уровня.
4. Заголовки: название документа — прописными, по центру, обычным начертанием;
   разделы — нумерованные «1. Предмет предложения», обычным начертанием, без фона.
5. Таблицы — сплошные тонкие чёрные линии (0,5 pt), шапка по центру, обычным начертанием;
   числа — по правому краю, без переносов; денежные суммы — «12 345 678» без знака валюты
   в ячейке, валюта указывается в шапке («руб.»).
6. Текст — связные абзацы официально-делового стиля, без маркированных списков с
   «жирными» лид-инами; перечисления — внутри абзаца через точку с запятой или в таблице.
7. Шапка документа: слева отправитель и его реквизиты, справа «Исх. № … от …» и адресат;
   внизу — подпись «должность / ФИО», дата, «М.П.».
8. Поля A4: 20 мм сверху и снизу, 20 мм слева, 15 мм справа.
9. Содержательное требование к ТКП: заказчик должен видеть, что предлагается оригинал
   либо изделие, максимально приближенное к оригиналу. В разделе «Предмет предложения»
   прямо формулируется принцип: оригинал — при законной возможности поставки; при её
   отсутствии — максимально приближенное изделие с документальным подтверждением каждого
   параметра. Первой строкой коммерческой таблицы идёт оригинал (пусть и справочно),
   далее — рекомендуемый вариант.

## Как собирать

Каркас — `templates/tkp_a4.html` в этом навыке (CSS уже внутри). Подстановка данных —
Python f-string или простой шаблонизатор; печать в PDF:

```bash
bash .claude/skills/pdf-analysis/scripts/html2pdf.sh tkp.html "ТКП-….pdf"
```

Перед отправкой открыть PDF через `Read` с `pages` и проверить: нет обрезанного текста в
узких колонках (для таблиц с деньгами используй `table-layout: fixed` и ширины в `th`),
нет пустых страниц, подпись не оторвана от текста.

## Проверка на «следы ИИ»

Перед выпуском прогони по HTML: `grep -c "<b>\|class=\"tag\|class=\"key\|background:"` —
должно быть 0 (кроме `background: #fff` в `body`). Списки `<ul>` допустимы только в
внутренних документах и без жирных лид-инов.
