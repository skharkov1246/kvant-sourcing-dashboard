Расхождение, которое надо знать до защиты

Разведка сделана по 857 позициям. Твёрдое наличие подтверждено по 93 позициям всей заявки. Пересекаются они только в 15. То есть оценка и подтверждённый склад стоят на разных строках: 78 твёрдых строк идут без оценки, а 743 оценённых строк не имеют подтверждённого наличия вовсе.

Практический вывод: закрытой считается позиция, попавшая в пересечение, а не любая из двух цифр по отдельности.

Как читать документ

  1. Уверенность A/B/C — чем обоснована наша цена. C значит оценка по аналогу: такую цифру защищать нечем, кроме класса изделия.
  2. «Основание нашей цены» под каждой строкой — дословно то, что было записано при оценке. Именно это придётся предъявлять.
  3. Цены приведены к доллару по курсу на 13 Sep 2026 из gt/data/fx_rates.json. Это справочный курс, не курс сделки — рядом с любой суммой оговорка обязательна.
  4. Ошибка разведки на объём считается только там, где цена продавца выше верха оценки: разница, умноженная на количество. Это мера промаха оценки, а не потеря по сделке — выставленная цена сюда не входит.
  5. Чего здесь нет: цен, выставленных заказчику. Они тянутся из приложенных к сделке файлов отдельным прогоном (gt/tools/bitrix_tkp.py) и лягут рядом с этими столбцами, когда выгрузка пройдёт.
