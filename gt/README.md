# ГТУ-библиотека — поставщики Solar & Siemens SGT-100…400

Справочный сайт для сорсеров КВАНТ по газовым турбинам **Solar Turbines**
(Saturn 20 … Titan 250) и **Siemens SGT-100…400** (линия Линкольн, ex-Ruston):
кому идти за каким типом запчастей, как читать шифровки партномеров, что видно
в таможне РФ и какие мировые базы покупаем.

Один самодостаточный HTML (встроенные CSS+JS, без внешних ресурсов), 8 вкладок:
Обзор · Машины · Номенклатура ЗИП · Шифровки PN · Поставщики · Наши запросы (Bitrix) ·
Таможня РФ · Базы данных.

## Структура

```
gt/
  data/suppliers.json   библиотека компаний (37): 30 верифицированных по SGT
                        (из zip/orders/sgt_exporters_contacts.csv, таможня РФ
                        HS 8411 2023–2026 + веб-верификация 05.08.2026)
                        + Solar-блок (публичные данные, контакты с сайтов)
  data/models.json      модельные ряды: 4×SGT + 9×Solar (мощность/КПД ≈, ISO)
  data/parts.json       номенклатура ЗИП: 8 систем, критичность, EN-термины для RFQ
  data/sgt400_checklist.json  мировой чеклист SGT-400: 141 компания по 7 сегментам
                        (камеры/DLE, лопатки, покрытия, материалы, MRO, трейдеры,
                        РФ/СНГ) с приоритетами и уровнями доверия — импорт из
                        сессии «Перфы» (ветка claude/project-continuation-drfnkf)
  data/pn_guide.json    шифровки PN: формат Линкольна (MW#####X), legacy-имена
                        (Typhoon/Tornado/Tempest/Cyclone), правила Solar, методика
  data/bitrix_gt.json   наши ГТУ-запросы из Bitrix: сделки с разметкой моделей и
                        (при живой выгрузке) запросы СП-166 с поставщиками —
                        «кто к чему предлагает». Сид собран из data/chat_snapshot.json;
                        полная выгрузка: tools/bitrix_gt.py (нужен BITRIX_WEBHOOK_URL)
  tools/bitrix_gt.py    выгрузка ГТУ-сделок + СП-166 из Bitrix24 → data/bitrix_gt.json
  site/index.template.html  шаблон (плейсхолдеры __..._JSON__)
  build.py              сборка → gt/public/index.html; таможенную сводку считает
                        на лету из zip/customs/out/customs_8411*.json
  public/index.html     собранный сайт (артефакт сборки, закоммичен для просмотра)
```

## Сборка и проверка

```bash
python3 gt/build.py            # → gt/public/index.html
```

Проверка перед PR — headless Chromium (Playwright): все вкладки открываются,
нет JS-ошибок, нет горизонтального оверфлоу (включая ширину 390px), фильтры
поставщиков работают.

## Данные: правила честности

- Контакты SGT-блока верифицированы (таможня + сайты, 05.08.2026); где данных
  нет — стоит «не найдено», ничего не выдумано.
- Solar-блок — компании с публично подтверждённым профилем; email/телефоны
  НЕ вносились (брать с сайта при первом RFQ).
- Мощности/КПД моделей — «≈» по открытым данным OEM; сверять с Gas Turbine
  World Handbook.
- Правила PN со статусом «⚠ проверить» подтверждать первым же IPC/КП.
