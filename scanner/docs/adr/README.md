# Журнал архитектурных решений (ADR)

Каждое решение записано в момент принятия, с контекстом и отвергнутыми
альтернативами. Смысл журнала — чтобы через год новый человек понял **почему**
сделано так, и не переделывал по кругу.

Формат: контекст → решение → последствия → отвергнутые варианты.
Решение не редактируется задним числом: если оно изменилось, пишется новый ADR
со ссылкой «заменяет ADR-XXXX».
