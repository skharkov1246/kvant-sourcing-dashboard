1. Общие рекомендации

Главное: 42 из 76 лучших КП — перекупщик WMS с ценами уровня OEM (шпилька $110 при себестоимости $0.8; кольцо $308 при фабричной цене $0.3 у Sanshan). Эти цены — не рынок производства, а маржа посредника. Не принимать. По всем WMS-позициям слать RFQ фабрикам с нашей целевой ценой.
  1. Целевая цена в переговорах — «наша расчётная себестоимость +20%» (колонка «Цель» в таблицах). Фабричные КП Sanshan подтверждают порядок цифр.
  2. Пул поставщиков: Sanshan (фабрика, металл+РТИ, 29 фабричных КП — базовый кандидат) · YLF, Fuxuan (РТИ — для конкуренции) · KAT (втулки). На каждый лот — минимум 2 КП.
  3. Разбить заказ на 2 риск-корзины: (А) РТИ/метизы/мелочь — заказывать сразу, брак некритичен; (Б) ответственные детали (поршень, гильза, шток, втулки, драйвер) — сначала образцы 1-2 шт + входной контроль материала, потом партия.
  4. Материал: все текущие фабричные КП — на китайском материале. Для корзины (Б) параллельно запросить цену на импортном (18CrNiMo7-6 / 40CrNiMoA ESR) — ожидаемо +40-60%.
  5. Цены EXW: до склада РФ добавить логистику/пошлину/НДС ≈ +25-40%. Даже с этим маржа против OEM-рынка кратная.
  6. Оплата: 30% аванс / 70% по фото готовой продукции и отчёту инспекции; новых поставщиков — через Trade Assurance/аккредитив.
  7. Гидромотор — не копировать: это покупной узел ($400-900 реально), в пилот не включать как «изготовление».

4. На что обратить внимание (красные флаги)

  • Худшие цены WMS для отклонения: шток 3115 6001 66 — $1763 (цель $72) · муфта 3115 2031 00 — $1322 (цель $24) · комплект 3115 9362 00 — $749 (цель $14.4) · кольцо 3115 6010 36 — $308 (цель $0.24) · шпильки — $88-110 (цель $0.96).
  • Sanshan котирует на китайском материале (их формулировка в переписке) — для корзины (Б) это стартовая цена, не финальная спецификация.
  • Комплекты уплотнений: цена комплекта скрывает качество компонентов — согласовать состав покомпонентно (какие манжеты PU, какие кольца NBR).
  • Позиции с одним КП — конкуренции нет: не подписывать до второго КП (YLF/Fuxuan закрывают РТИ быстро).
  • Таможенный бенчмарк (22 тыс. деклараций РФ): медиана перфораторного импорта 7.2 USD/кг — грубая проверка «цена/вес» при приёмке КП.
  • Критичные детали (поршень/гильза/хвостовик): ресурс решает термообработка, не только сталь — приёмка по нашей техкарте (цементация: глубина слоя, HRC поверхн./сердцевина, УЗК). Без этого дешёвая деталь = дорогой простой.
