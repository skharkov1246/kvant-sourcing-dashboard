# ГПУ-библиотека — газопоршневые Cummins · Caterpillar · Jenbacher

Справочник сорсинга по **газопоршневым установкам**: кому идти за каким ЗИП,
кто реально изготавливает узлы под шильдиком OEM, какие аналоги считаются
нормальными и через какие страны это ходит.

Сделан по образцу ГТУ-библиотеки (`gt/`), но это отдельный сайт на отдельном
домене: техника, номенклатура, поставщики и логика поиска у поршневых машин
другие, и смешивать их с турбинами было бы вредно.

Один самодостаточный HTML (встроенные CSS+JS, без внешних ресурсов), **12 вкладок**:
Обзор · Машины · Номенклатура · Наш спрос · Аналоги · Субпоставщики ·
Поставщики · Каналы · Шифровки PN · Наши запросы · Таможня · Плейбук.

## Что внутри

**Наш спрос — 94 реальные позиции.** Лист «Энергосети» рабочей заявки:
Cummins QSV/QSK (59 позиций) и INNIO Jenbacher (35). Вилки цен по 85 позициям,
**61 живая проверка конкретных продавцов** (цена, наличие, срок отгрузки).
Лот в деньгах: **$0,92 млн по нижней границе — $2,87 млн по верхней.**
Больше половины стоимости — зажигание, и это ровно та группа, где есть
качественные аналоги.

**Аналоги — 18 разобранных семейств (78 аналогов на 178 номеров OEM) плюс
машинный разбор каталогов MOTORTECH: 134 записи и 296 номеров OEM.**
Каталоги MOTORTECH — кросс уровня A, где изготовитель компонента сам заявляет
эквивалентность: `06.50.151 = CAT 418-4861 / 232-6346 / 165-1589 / 124-0749`.
Разобраны три PDF (CAT G3500, CAT G3400, Waukesha VHP) скриптом
`tools/parse_motortech.py` — по брендам: WAUKESHA 73, ALTRONIC 64,
CATERPILLAR 57, MOTORTECH 18, IMPCO 2, CHAMPION 1. Плюс опубликованные таблицы
TECHIE по Cummins и Jenbacher, кроссы Denso, Champion, Elring, MANN, Donaldson
и альтернативы ONERGYS. Всего по сайту **617 уникальных номеров деталей**.

**Ведомости ЗИП с количеством на двигатель.** Для CAT G3516 — 50 позиций из
каталога применяемости IPD: 9 коренных вкладышей, 16 шатунных, 32 втулки
коромысла, 16 гильз, с развилками (степень сжатия 8.0:1 или 11.0:1,
ранняя/поздняя втулка распредвала, группа водяного насоса, термостат 180/190 °F).
Превращает «нужны вкладыши на G3516» в спецификацию за минуту.

**Маршрутизация.** В карточке любой позиции спроса — блок «кому слать запрос»:
подбирает поставщиков из пула по OEM и системе, сортирует по рейтингу, показывает
топ-4 с контактом и подсказывает стратегию по классу позиции (критично-дорогое /
расходник с ресурсом / мелочь под изготовление по чертежу).

**Субпоставщики.** Ключевая мысль сайта — **правило шильдика**: ГПУ собрана из
чужих компонентов, и на турбине, генераторе, теплообменнике, катушке, муфте
стоит табличка настоящего изготовителя. Десяток фотографий шильдиков с площадки
превращает «OEM не поставляет» в обычную закупку у изготовителя узла, дешевле
в 2–10 раз. По каждой системе — кто это может быть, с честной пометкой
`confirmed` / `market` / `check`.

**Поставщики — 35 компаний с рейтингом.** Считается в `build.py` по пяти осям
(проходимость в РФ ×3, доказанность ×3, глубина по ГПУ ×2, сток ×2,
отзывчивость ×1) — веса лежат в данных и показаны на сайте, руками рейтинг
не правится.

**Каналы.** Турция, Китай, ЕАЭС/Казахстан, ОАЭ, Индия, ЕС, США, РФ — что через
какую страну реально ходит, чем рискуем и как работать. США здесь ценны не как
поставщик, а как **ценовой репер**: открытая розница с ценами и наличием
(турбина 4025166 — $16 493,84) даёт точку отсчёта для торга с трейдерами.

## Структура

```
gpu/
  data/models.json        модельные ряды 3 OEM (31 машина) + 9 смежных линеек
  data/parts.json         номенклатура ЗИП по 14 системам + интервалы ТО и EN-термины для RFQ
  data/demand.json        ← генерируется tools/build_demand.py, руками не править
  data/analogs.json       18 семейств кросс-номеров, правила оценки аналога A–D
  data/subsuppliers.json  правило шильдика + кто делает узлы по 12 системам
  data/suppliers.json     35 поставщиков (12 перенесены из gt/data/rfq_suppliers.json)
  data/channels.json      8 логистических каналов с оценкой и плейбуком
  data/pn_guide.json      шифровки номеров: Cummins, CAT, Jenbacher, MOTORTECH,
                          Altronic, Denso, Champion, Fleetguard + типовые ловушки
  data/bitrix_gpu.json    наши запросы (СИД; живая выгрузка — tools/bitrix_gpu.py)
  data/customs.json       карта кодов ТН ВЭД по ГПУ + готовая инструкция выгрузки
  data/playbook.json      порядок ведения заявки + шаблоны RFQ (копируются по кнопке)
  data/motortech_cross.json ← генерируется tools/parse_motortech.py, руками не править
  data/partlists.json     ведомости ЗИП по машинам с количеством на двигатель
  tools/build_demand.py   спрос: gt/data/rfq_demand.json + rfq_prices.json → data/demand.json
  tools/parse_motortech.py разбор Application Guides MOTORTECH из PDF → кросс-таблицы
  tools/bitrix_gpu.py     живая выгрузка сделок и СП-166 по ГПУ из Bitrix24
  site/index.template.html  шаблон (плейсхолдеры __..._JSON__)
  build.py                сборка → gpu/public/index.html; считает рейтинг поставщиков
  public/index.html       собранный сайт (артефакт сборки, закоммичен для просмотра)
  public/_worker.js       гейт Basic Auth (fail-closed)
```

## Сборка и проверка

```bash
python3 gpu/tools/build_demand.py            # пересобрать датасет спроса (если менялась заявка)
python3 gpu/tools/parse_motortech.py [дир]   # пересобрать кросс-таблицы из PDF MOTORTECH
python3 gpu/build.py                         # → gpu/public/index.html
```

`parse_motortech.py` берёт PDF из каталога, указанного аргументом (по умолчанию
`gpu/tools/pdf`). Сами PDF в репозиторий не кладём — их нужно скачать браузером
по ссылкам, зашитым в скрипт: сайт MOTORTECH закрыт антибот-защитой и `curl`
получает заглушку. Если PDF нет, скрипт честно печатает ссылки и оставляет
закоммиченный `data/motortech_cross.json` нетронутым, сборка не падает.

Проверка перед PR — headless Chromium (Playwright): все 12 вкладок открываются,
нет JS-ошибок, нет горизонтального оверфлоу (в т.ч. на 390px), работают фильтры
и сортировка спроса, раскрываются аккордеоны номенклатуры и аналогов, работают
фильтры поставщиков по региону и OEM, корректна тёмная тема. Прогон 13.08.2026 —
чисто на 1440px и 390px.

## Данные: правила честности

- Вилки цен — **оценка по открытой рознице, а не наши закупочные**. Нижняя
  граница почти везде = азиатский аналог, верхняя = дилер OEM.
- Уровень доверия к аналогу помечен буквой: **A** — кросс от изготовителя
  компонента, **B** — от независимого специалиста рынка, **C** — реверс из Азии,
  **D** — «продавец написал в карточке» (доказательством не считаем).
- Субпоставщики помечены `confirmed` / `market` / `check`. Где прямого
  подтверждения нет — так и написано, список не добивается наугад.
- Где наша автоматическая проверка сайта поставщика не прошла (403, антибот,
  цены только после логина) — это отмечено значком ⚠ прямо в карточке.
- Мощности и КПД машин — «≈» по открытым данным, зависят от газа и версии.
- Таможня по ГПУ **не выгружена** — и на вкладке это написано прямо, вместе с
  готовой инструкцией, как её поднять (см. ниже).

## Таможня: как поднять (5 минут, код писать не нужно)

Нужные коды ТН ВЭД (8407, 8409, 8511, 8502, 8414, 8421) никогда не выгружались —
в `zip/customs/out/` лежат только буровые и карьерные группы. Существующий
workflow **«ZIP customs — glbs.io recon/pull»** принимает список HS параметром:

```
Actions → ZIP customs → Run workflow
  mode = pull, method = search        (бесплатно, без цен)
  hs = 8511,8409,8407                 (второй заход: 8502,8414,8421)
  period_start = 2023-01-01, period_finish = 2026-08-31
  extra_pn = 4380132,5373898,4351035,1236100,1214569,334976,433894,LF9050,AF899M,WF2075,4025166
  extra_re = JENBACHER|CUMMINS|CATERPILLAR|QSV|QSK|G35|СВЕЧ.{0,12}ЗАЖИГ|ГАЗОПОРШН
```
Нужен секрет `GLBS_API_KEY`. Результат коммитится в `zip/customs/out/`,
после чего достаточно пересобрать сайт.

## Деплой

Отдельный проект Cloudflare Pages **kvant-gpu** → `kvant-gpu.pages.dev`,
**закрыт Basic Auth**. Публикуется workflow `.github/workflows/gpu-deploy.yml`;
триггер — изменения `gpu/**` в `main`. Свой домен привязывается в панели
Cloudflare (Pages → kvant-gpu → Custom domains).

Нужен секрет проекта `BASIC_AUTH_PASS` (логин — `BASIC_AUTH_USER`, по умолчанию
`kvant`). **Без секрета воркер отдаёт 503 и никого не пускает** — это осознанный
fail-closed: внутри стоимость нашего лота с вилками закупки, разрывы цен
OEM/аналог, оценка санкционной проходимости поставщиков и номера сделок Bitrix.
Если секрет `BASIC_AUTH_PASS` задан в GitHub, workflow сам прокинет его в Pages.

Перед сборкой workflow пытается обновить `data/bitrix_gpu.json` живой выгрузкой
из Bitrix24 (секрет `BITRIX_WEBHOOK_URL`). Если секрета нет или Bitrix
недоступен — берётся сид, сборка не падает.

> **Изменение в чужом файле, которое стоит проверить.** В `deploy.yml` (дашборд
> сорсеров) в `paths-ignore` добавлен `gpu/**` — по той же логике, по которой
> 13.08.2026 туда добавили `ove/**`: иначе каждый коммит в `gpu/**` запускал бы
> ещё и полную 8-минутную пересборку дашборда. Отдельного согласования на это
> не было; если владелец против — достаточно убрать `"gpu/**"` из списка.
