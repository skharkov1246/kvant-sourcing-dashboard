# CFD печи КС ОВЭ-75 — кейс для запуска на AWS

Статус: **готов к запуску, ждём доступ к AWS** (решение владельца 15.08.2026: «ЦФД печей сделаем»).
Цель — расчётное обоснование печи кипящего слоя методами вычислительной гидродинамики:
дифференциатор ТКП уровня мирового лицензиара. В гарантийные показатели результаты не идут
(без валидации на пилотных данных погрешность многофазного CFD ±20–30 %) — идут в проектные
обоснования (решётка, фурмы, зона сепарации) и в защиту ТКП.

## 1. Постановка

| | |
|---|---|
| Объект | печь КС окислительного обжига медного концентрата, 930 °C, автогенный режим |
| Геометрия | **фактическая из ИД ч.1 (стр. 417–418)**: конус 21° — подина Ø 6 000 мм (28,3 м²) → газоход Ø 8 390 мм (55,3 м²), высота конуса 6 450 мм, общая до газохода 9 200 мм; решётка — 583 грибообразных сопла; слой ~2,2 м (проверено L1-BED; уклон конуса 0,185 на сторону — 21° это полный угол; напряжённость по зеркалу ≈8,9 т/(м²·сут) — выше практики 4–8, запас площади пода — вопрос Гипроникелю). | Дутьё | 11 342 нм³/ч, обогащение 52 % O₂, через распределительную решётку (конфигурация — варьируемый параметр) |
| Твёрдая фаза | бидисперсная: огарок 449 мкм (слой, ~93 т) + свежая шихта 25,5 мкм (подача 13,5 т/ч, влажность 12,5 %) ; ρp ≈ 5 300 кг/м³ |

## 2. ПО и метод

- **MFiX** (NETL, open-source) — Two-Fluid Model (TFM) с полидисперсностью для полного объёма печи;
  контрольный прогон MFiX-PIC (parcel-in-cell) для проверки сегрегации фракций.
- Альтернатива: OpenFOAM (twoPhaseEulerFoam/multiphaseEuler) — если MFiX упрётся в химию.
- Сетка: 3D, 2–5 млн ячеек (базовая), локальное сгущение у решётки; шаг времени ~1e-4 с;
  физическое время прогона 20–40 с (статистика после выхода на квазистационар).

## 3. Матрица прогонов (8 шт.)

| № | Прогон | Что даёт |
|---|---|---|
| 1–3 | сеточная сходимость (1/2,5/5 млн ячеек), основной режим | доверие к сетке |
| 4 | базовый: осн. вариант, тепло 2,86 ГДж/т | карта T и O₂ слоя, доля объёма T>960 °C (риск агломерации), профиль уноса |
| 5 | базовый с теплом 2,378 ГДж/т | чувствительность к спору F-HEAT: удержит ли слой 930 °C |
| 6 | вспомогательный режим (мазутная топка, больше газа) | унос 29 % — воспроизводится ли |
| 7–8 | две конфигурации решётки (шаг/живое сечение сопел) | Δp решётки, мёртвые зоны, обоснование конструкции |

## 4. Выходы (deliverables)

1. Поля T, O₂, порозности по объёму слоя (карты + анимации для защиты ТКП);
2. Доля объёма слоя с T > 960 °C (порог агломерации) по режимам;
3. Расчётный унос по фракциям vs наши балансовые 19/29 % (валидация);
4. Δp решётки и слоя vs заявленное дутьё 0,09–0,12 МПа (проверка воздуходувки, блок L1-EL);
5. Рекомендации: конфигурация решётки, положение фурм подачи шихты, высота зоны сепарации;
6. Отчёт «Расчётное обоснование печи КС методами CFD» — приложение к БИ (со статусом
   «проектное обоснование, не гарантийный расчёт»).

## 5. Ресурсы и бюджет (оценка)

- Один прогон: 48–96 ч на 128–256 ядрах → 6–25 тыс. ядро-часов; матрица целиком **60–150 тыс. ядро-часов**.
- AWS: hpc7a.96xlarge (192 физ. ядра) или c7i spot-парк; ParallelCluster + Slurm; S3 для полей.
- Бюджет: ориентировочно **$2–6 тыс.** на spot-мощностях (зависит от региона и глубины матрицы);
  срок 3–4 недели календарных (1 неделя постановка/сетки, 2 недели прогоны, 1 неделя обработка).
- От владельца: доступ (IAM-роль с EC2/S3/ParallelCluster либо готовый кластер) + лимит бюджета.
  Кейсы, скрипты запуска и обработку полей готовит и ведёт Claude (КВАНТ).

## 6. Риски и честные оговорки

- Многофазный CFD без пилотной валидации — ±20–30 %: выводы формулируем сравнительно
  («конфигурация A даёт на N % меньше мёртвых зон, чем B»), а не абсолютно;
- химия огрублена до брутто-реакций — состав газа сверяем по интегралам, не по локальным полям;
- габарит печи — пока наша оценка: **до старта прогонов получить табл. 24/25 ИД** (флаг F-KS),
  иначе геометрию фиксируем допущением с пересчётом за 2–3 дня после получения данных.
