# Старт за 60 секунд

Файл для того, кто открыл репозиторий впервые — человека или агента.
Машинная версия того же: `.agent/manifest.json`.

## Что это

Монорепозиторий инструментов КВАНТ. Внутри семь независимых продуктов:

Три библиотеки оборудования — **ГПУ** (газопоршневые), **ГТУ** (газотурбинные),
**ГШО** (горно-шахтное и горнопроходческое) — плюс дашборд и проекты под заказчика.
Все семь сайтов закрыты одним входом Cloudflare Access; портал с плитками — на
kvant-sourcing-f122, права на плитки назначаются в `/admin` (см. `access/README.md`).

| Что | Где | Сборка | Сайт | Право |
|---|---|---|---|---|
| Дашборд сорсеров (Bitrix24) | корень | `main.py` | kvant-sourcing-f122 (портал и `/dashboard`) | `dashboard` |
| ГШО — горно-шахтное оборудование | `zip/` | `zip/build.py` | kvant-zip | `zip` |
| ГТУ — газотурбинные установки | `gt/` | `gt/build.py` | kvant-zip, раздел `/gt/` | `gt` |
| ГПУ — газопоршневые установки | `gpu/` | `gpu/build.py` | kvant-gpu | `gpu` |
| ОВЭ-75 | `ove/` | `ove/build.py` | kvant-ove | `ove` |
| Гидрометаллургия | `gidromet/` | `gidromet/build.py` | kvant-gidromet | `gidromet` |
| Базовый проект ГОКа | `factory/` | без сборки | kvant-gok | `gok` |

Идентификатор права у ГШО остался прежним (`zip`) — переименование не должно отнимать
доступ у тех, кому он уже выдан. Адреса `pages.dev` тоже прежние: смена адреса
потребовала бы нового проекта Pages и сломала бы все сохранённые ссылки.

## Где данные

`data/catalog.json` — каталог всех наборов данных: путь, объём, число записей,
ключи, кто и когда обновлял, какие файлы читают, оценка чувствительности.
Пересобрать: `python scripts/build_catalog.py`.

## Как найти значение

`data/index.json` — поисковый индекс: 32 619 ключей (парт-номера, производители,
модели, коды ТН ВЭД, организации) → файл и номер записи.

```bash
python scripts/lookup.py 4380132              # где лежит парт-номер
python scripts/lookup.py 4380132 --show       # плюс сами записи
python scripts/lookup.py MOTORTECH --group oem
python scripts/lookup.py denso --near         # по подстроке
```

Замер: поиск по номеру — 0,12 с против 8,4 с перебором по дереву. Индекс не
содержит контактов и сумм; список исключённых полей лежит внутри самого файла
и проверяется тестом.

Оттуда же видно, что 43 набора помечены как конфиденциальные — это контакты
поставщиков, бюджеты сделок, таможенные декларации и метрики сотрудников.

## Проверки перед PR

```bash
python -m pytest -q                          # тесты ядра, ~0,2 с
ruff check .                                 # ошибки кода
python scripts/build_catalog.py --check      # каталог данных актуален
```

Правка вёрстки дашборда — обязательно рендер и валидация:

```bash
python -c "import sys,types;sys.modules.setdefault('dotenv',types.SimpleNamespace(load_dotenv=lambda *a,**k:None));\
sys.path.insert(0,'.');import dashboard;from tests import fixture;\
dashboard.write(fixture.build_metrics(),{'source':'rules','items':[]},'smoke/index.html')"
python scripts/validate_dashboard.py smoke/index.html
```

Правка логики метрик — `python main.py --dry-run` (нужен `BITRIX_WEBHOOK_URL` в `.env`).

То же самое автоматически выполняет `.github/workflows/gate.yml` на каждый PR.
