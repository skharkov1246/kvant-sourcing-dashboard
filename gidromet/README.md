# gidromet — сайт инженерного заключения по гидрометаллургии

Открытый сайт с независимым инженерным заключением ООО «Квант» по проекту переработки
медно-золотого концентрата месторождения в Республике Карелия.

**Адрес:** kvant-gidromet.pages.dev — отдельный проект Cloudflare Pages, без пароля.

## Устройство

```
gidromet/
  site/index.template.html   вёрстка и вся логика отрисовки; плейсхолдеры __X_JSON__
  data/*.json                содержание разделов, по файлу на вкладку
  build.py                   подстановка данных в шаблон -> public/index.html
  tools/harvest.py           раскладка результатов расчётного потока по data/*.json
  public/index.html          собранная страница, её и деплоит workflow
```

Сборка: `python3 gidromet/build.py`. Файла данных может не быть — тогда вкладка честно
показывает «раздел собирается», сборка не падает.

## Вкладки

Шесть групп: Итог, Сырьё, Технология, Завод, Деньги, Работа — всего двадцать вкладок.
Список задан в шаблоне константой `GROUPS`; идентификатор вкладки совпадает с именем
файла данных (кроме вкладки «Главное», которая читает `project.json`).

## Формат данных

Каждый файл — объект с полями `lead`, `tiles`, `boxes`, `sections`, `footnote`.
Отрисовщик универсальный: в `sections` допустимы `text`, `boxes`, `list`, `table`,
`steps`, `timeline`, `cards`, `chart`. Два раздела имеют дополнительные поля:
`marshruty.json` — массив `routes`, `postav.json` — массив `blocks`.

## Числа

Все величины восходят к воспроизводимым моделям каталога `factory/model`
(запуск: `python3 factory/model/<модель>.py`) либо к документам исходного досье.
Сводный вывод всех моделей собирается в один файл и служит единственным источником
чисел при наполнении разделов — это удерживает двадцать разделов от противоречий.

## Деплой

`.github/workflows/gidromet-deploy.yml` — срабатывает на push в `main` при изменениях
в `gidromet/**`. Проверяет отсутствие `_worker.js` (сайт открытый), отсутствие внешних
ресурсов (страница обязана быть самодостаточной) и отсутствие незаменённых
плейсхолдеров, затем деплоит `gidromet/public` в проект `kvant-gidromet`.

Правка `gidromet/**` не запускает пересборку дашборда сорсеров: `gidromet/**` внесён
в `paths-ignore` основного `deploy.yml`.
